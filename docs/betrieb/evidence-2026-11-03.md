## Collector validation

The shadow collector is exercised offline with negative cases for empty/missing comparisons,
pending/inconclusive verdicts, a shared observer misinterpretation, inconsistent agreement
flags, unproven batches, timeouts, unfinished recordings and wrong repositories. The launcher
is tested to refuse active writes on queue-lab, to pass `--shadow` only there and to wait for
`/readyz`. This is collector evidence; real comparison results are reported separately.
When a future shadow comparison is incomplete, its diagnostic includes a bounded verdict and
the names of differing fields without printing arbitrary report text or pull request content.
An independent review also found potential false agreements. The collector now requires a
valid dequeue history (including an empty history), a green batch that contains the PR, a PR
actually watched, and independent proof that Mergify performed each reported merge. Event-log
recordings fail closed on malformed or truncated pages. Startup failures no longer print full
service log lines. Older recordings without the merger classification cannot pass this check.
